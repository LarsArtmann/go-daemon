## 3. Tag with the annotation below (annotated, signed if available)

```text
go-daemon v0.3.0

Vary: Accept on every written response.

WriteEncoded (and through it WriteJSON/WriteErrorf) now adds
"Vary: Accept" to every response: encodings are commonly chosen from the
request's Accept header, so caches must not reuse a stored response
across different Accept preferences. The header is added rather than set,
preserving handler-declared variance such as "Vary: Authorization".

Behavior change, not a bug fix — hence the minor bump. Full notes:
https://github.com/LarsArtmann/go-daemon/blob/master/CHANGELOG.md
```

Command: `git tag -a v0.3.0 -m "$(cat docs/release/v0.3.0-draft.md)"` after
trimming to the block above, then `git push origin v0.3.0`.
